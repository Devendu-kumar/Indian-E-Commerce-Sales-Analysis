# Indian E-Commerce Sales Analysis

## Project Overview

This is my first practical Excel Data Analytics project.

I analysed an Indian e-commerce sales dataset using Microsoft Excel
and created a dashboard to understand sales, profit and business
performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- VLOOKUP
- SUMIFS

## Analysis Performed

- Data Audit
- Data Cleaning Check
- Overall Sales and Profit Analysis
- Category-wise Analysis
- Sub-Category-wise Analysis
- State-wise Sales Analysis
- City-wise Sales Analysis
- Monthly Sales and Profit Analysis
- Target vs Actual Sales Analysis
- Sales Dashboard
